Lab Report: GrowthGarden Achievement Refinement

1. About the Use Case

Why this portal is required for autism kids: Children on the autism spectrum often possess strong visual-spatial processing abilities but struggle with abstract numerical concepts and traditional text-heavy instruction. This portal provides a sensory-friendly, highly visual environment that translates abstract addition into tangible "growth" within a garden.

Challenges addressed:

  • Abstract Thinking: Translating numbers into physical objects (flowers, trees) helps bypass abstract processing hurdles.
  • Executive Functioning: Breaking down math into "watering" and "sunlight" tasks provides clear, sequential structure.
  • Fine Motor/Coordination: Drag-and-drop and click-to-count operations provide tactile feedback and improve hand-eye coordination.

Highlights and Novelty: The "GrowthGarden" introduces a living feedback loop. Unlike standard quizzes, the user's success is physically represented by an evolving ecosystem. The novelty lies in the Achievement Certificate system which generates a personalized, high-fidelity binary PNG to celebrate micro-wins, fostering emotional resilience.

Importance of Visualisation: Visualisation acts as a "cognitive bridge." By seeing the plant grow taller with every correct answer, the child establishes a direct neural link between mathematical success and positive environmental change, making the learning "sticky."

2. Operations and React Implementation

Operation Name Expected Output React Concepts Used Improvement to Application
Visual Question Generation Random objects (apples/flowers) appearing for addition. useState, useEffect, useCallback Ensures every session is unique and prevent pattern-memorization, encouraging active thinking.
Tactile Basket Submission Basket pulses and counts items dropped into it. Conditional Rendering, CSS Animations Provides immediate "tactile" feedback, helping autistic learners feel a sense of object permanence in math.
Garden Growth Logic Plant evolves from Seedling to Tree based on score. State Management (Lifting State Up) Visualizes progress over time, reducing anxiety by showing that "even mistakes are part of the process."
Achievement Capture A high-quality certificate PNG saved to user's device. Refs (useRef), External API (Canvas/Blob) Allows for tangible, offline recognition of success which boosts self-esteem and parent-child interaction.

3. Improvements for Autism Kids

Memory Improvement: The use of consistent spatial placement for the "Basket" and "Garden" builds muscle memory and visual recall of mathematical sums.

Contextual Learning: By associating math with "Sunlight" and "Water," children learn that mathematics is a tool for understanding and nurturing the world around them, not just a classroom chore.
